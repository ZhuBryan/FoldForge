# Depth backend benchmark: MiDaS vs Depth Anything V2

Generated by `examples/bench_depth.py`. Each depth backend runs over the sample
photos, is masked to the subject with the same GrabCut segmentation, and folded
with the corrugation engine (`folds=30`). Both backends normalise to the same
`0..1` (1 = nearest) convention, so the columns are directly comparable.
Depth-map correlation between the two on `swallowtail` is **+0.83**, confirming
the near/far orientation matches (reliefs are not inverted).

Metrics:

- **Fold error** — the engine's `result.error` (how faithfully one crease
  pattern reproduces the estimated relief). Lower = smoother/more coherent.
- **Depth-edge sharpness** — mean masked Sobel-gradient magnitude of the depth
  map; the "resolves depth edges N% sharper" proxy from the README. Higher =
  crisper subject detail.

Environment: CPU-only sandbox (`torch 2.12.1+cpu`, `transformers 5.14.1`),
`depth-anything/Depth-Anything-V2-Small-hf`. Real, measured numbers.

## Read

- **Depth Anything V2 folds to a markedly lower error** on 4 of the 5 shared
  samples (mean 0.078 vs 0.134) — its relief is more coherent, so a single
  corrugation reproduces it better. `ginkgo` drops to 0.009.
- **It resolves edges sharper on average** (mean 0.050 vs 0.039, ~+30%), driven
  by textured subjects (`starfish` 0.127 vs 0.033, `moth`, `ginkgo`). MiDaS
  is slightly sharper on the smooth-winged `swallowtail`/`fish`/`butterfly`.
- Net: Depth Anything V2 Small is the better default when fine near/far detail
  matters; MiDaS small stays the zero-extra-dependency fallback.

## Note on the one missing cell

`starfish` uses a GrabCut rect over a ~700k-pixel image; a single GrabCut pass
took ~37 s in the CPU sandbox, and Depth Anything's own CPU inference adds
~15 s, so the folded `starfish` run for the DA backend exceeded the sandbox's
per-command wall-clock cap. Its sharpness cell is measured (mask is
model-independent); its fold-error cell is left to be filled by re-running
`python examples/bench_depth.py` on Bryan's machine, where GrabCut is seconds.
